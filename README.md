# bday89

🕷️ Happy Birthday Raju - Spider-Man Birthday Scrapbook Website

A Spider-Man / Spider-Verse themed interactive birthday website with music, photo scrapbook chapters, dynamic scroll-driven backgrounds, and celebratory interactive overlays.

## Running Locally

Simply open `site/index.html` in your browser, or run:

```bash
npm start
```
*or double-click `run.bat` on Windows.*
